# Проверки

Фактические результаты локального завершающего прогона 26 сентября 2026. Команды и воспроизводимая конфигурация приведены в README и GitHub Actions.

- Unit: 9 тестов правил доступности прошли, включая неоднозначные времена DST и переходы в полночь.
- Integration: 14 HTTP/PostgreSQL тестов прошли. Два независимых Nest-приложения, отдельные Prisma pools, PostgreSQL 17.4, миграции применены к `forma_test`.
- Главные конкурентные сценарии: один победитель из двух; разные пересекающиеся начала; один победитель из десяти; два мастера одновременно; EXCLUDE отклоняет прямой INSERT.
- Повторный demo seed выполнен дважды без ошибок.
- Frontend и backend production build, typecheck, ESLint и Prettier check прошли.
- Playwright / Chromium: 6 сценариев прошли (23,6 с): полный цикл записи/отмены, админские правки, сохранение выбора при входе, конфликт занятого слота, неверные URL, меню с клавиатуры и reflow при 200%.
- `pnpm audit`: известных уязвимостей не найдено, включая зависимости разработки.
- Docker Engine отсутствует локально. Реальный Docker build/Compose запуск локально не заявляется.
- 12 скриншотов четырёх экранов на 375/768/1440 сохранены Playwright в `docs/screenshots`. Проверено отсутствие горизонтального переполнения; главная, запись и админка просмотрены визуально.
- Проведено независимое ревью; три замечания исправлены, детали в REVIEW.md.
- Первый GitHub Actions прогон повторил все проверки кода и тесты успешно, собрал оба Docker-образа, применил миграции к чистой БД и запустил API. Проверка веб-контейнера выявила проблему health check с `localhost`; адрес заменён на явный IPv4 `127.0.0.1`. Повторный результат фиксируется после завершения CI.

Публичный хостинг приложения не следует из публикации кода. Фактические ссылки будут указаны в итоговом сообщении.
